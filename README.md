# Hospital Analytics Database Project

This project demonstrates a hospital management database built in MySQL Workbench.

## 📂 Files Included
- `hospital_analytics.sql` → SQL dump (schema + data)
- `project_presentation.pptx` → PowerPoint presentation explaining the project
- `er_diagram.png` → ER diagram of the database (optional)

## 🚀 How to Run
1. Open MySQL Workbench.
2. Import `hospital_analytics.sql` into your MySQL server.
3. Review the ER diagram and PPT for project overview.

## 📝 Project Overview
The database includes tables for:
- Doctors
- Patients
- Appointments
- Treatments

This schema is designed to analyze hospital operations and patient care.
